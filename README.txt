N4IA_LOVE_U_4LL
===============

Main page: N4IA_LOVE_U_4LL.html
Upload the whole folder and keep the folder structure as it is.

Contents
  N4IA_LOVE_U_4LL.html                  the game (HTML, CSS and JavaScript in one file)
  assets/sprites.png                    character animation frames (idle, walk, run, jump, poses)
  assets/world.jpg                      background
  assets/music.mp3                      background music (LOVE U 4LL 8-bit intro, 128 kbps)
  assets/fonts/MSW98UI-Bold.otf         title font (supplied for this project)
  assets/fonts/dm-mono-latin-*.woff2    body font, DM Mono
  assets/fonts/DM-Mono-OFL.txt          DM Mono license (SIL Open Font License 1.1)

Serving notes
  - Open it through a web server (http:// or https://). Opened straight from disk (file://),
    the music will not load, because browsers block that kind of file request.
  - If your server needs the start page to be index.html, rename N4IA_LOVE_U_4LL.html to index.html.
  - The Pause button and the P key open https://www.youtube.com/@papionofficial in a new tab.
  - Best score is kept in the visitor's browser (localStorage). Nothing is sent anywhere.
  - No external requests are made while playing, apart from the YouTube link when clicked.

Check before going public
  - The license of MSW98UI-Bold.otf (it is embedded and served to visitors).
